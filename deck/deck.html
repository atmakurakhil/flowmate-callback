How it works

Enquiry in. Call out. Owner informed.

1 · Lead landsForm, Meta lead ad, missed call or Cal.com booking hits the server. No consent, no call.
2 · Bolna callsWithin a minute, in the caller's language. First sentence says it is an AI.
3 · Qualify + bookAnswers only from the owner's written details. Two or three questions. Books a real open slot via tools.
4 · Owner gets itTranscript, 3-line summary, HOT / WARM / COLD with the caller's own words, WhatsApp confirmation drafted.

Trust, in code

A voice agent that cannot make things up about your business.

  • Consent or no call. A lead without recorded consent is rejected (HTTP 422) before any dial.
  • It says it is an AI in the first sentence, in every language. Tested for every combination, then re-checked on the transcript after each call.
  • No invented prices. Facts come only from the owner's profile; a post-call audit flags any number the agent said that the owner never wrote, so the owner can correct it.
  • One call per number per 24 hours, 09:00–21:00 IST only. Live mode dials only an allowlist.
52 TESTS PASS
Built on

Bolna end to end.

  • Bolna agent API: agent JSON built in code, per-language prompts, check_slots / book_slot tools mid-call, extractions for name, concern, urgency.
  • Sarvam bulbul voices and transcription for Telugu, Hindi and English; Bolna telephony on its default +91 number for trials.
  • FastAPI + SQLite server: webhooks verified by Bolna source IP and URL token, then the call is re-read from the API.
  • Meta lead-ad webhook (signature checked) and Cal.com bookings in; a WhatsApp follow-up sequence and a weekly owner report out.
